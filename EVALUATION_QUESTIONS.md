# Evaluation Questions

These questions are useful for a demo or grading walkthrough.

| Question | Expected Answer |
| --- | --- |
| Which countries in South America are landlocked? | Bolivia and Paraguay. |
| What is the capital of Brazil? | Brasília. |
| Which country includes the Galápagos Islands? | Ecuador. |
| What language does Suriname use? | Dutch. |
| Which country is the only Portuguese-speaking country in South America? | Brazil. |
| What is the Pantanal? | A major tropical wetland system mostly in Brazil, also extending into Bolivia and Paraguay. |
| What is the Atacama Desert known for? | Extreme dryness, astronomy, mining, salt flats, and distinctive landscapes. |
| Which countries are associated with the lithium triangle? | Argentina, Bolivia, and Chile. |
| What is Mercosur? | A South American regional trade bloc associated with economic integration. |
| What is Lake Titicaca? | A high-altitude Andean lake on the Peru-Bolivia border. |
